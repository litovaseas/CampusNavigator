**校园智能导航与路径搜索可视化系统**

校园地图建模与路径规划可视化项目，支持 BFS、DFS、Dijkstra 三种图搜索算法的交互式演示。

**功能**
- 三种搜索算法：DFS 深度优先、BFS 广度优先、Dijkstra 最短路径
- 图形化交互界面：基于 tkinter，支持起点/终点选择与算法切换
- 搜索过程动画演示：逐帧展示节点访问、松弛操作及最终路径
- 校园地图建模：12 个真实地点节点，加权有向图表示路径连接

**项目结构**
```
CampusNavigator/
├── navigator.py   主程序
└── README.md
```
**技术要点**
- 加权有向图建模：邻接表存储，支持非对称路径权重
- Dijkstra 算法：基于 heapq优先队列实现，包含松弛操作
- BFS：基于队列实现，保证边数最少的路径
- DFS：基于栈实现，支持全路径遍历
- GUI：tkinter Canvas 绘制地图，逐帧动画展示搜索状态
- 代码结构：数据层、算法层、视图层三层分离
